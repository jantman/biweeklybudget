# Contract: Plaid entries on the Screenshots page

Each entry is generated by `docs/make_screenshots.py` as `<filename>.png` plus a
`<filename>_sm.png` thumbnail, with a section in `docs/source/screenshots.rst`. They
follow "OFX Transactions", in this order.

| filename | title | page | shows |
|----------|-------|------|-------|
| `plaid-update` | Plaid Update | `/plaid-update` | Plaid Update Transactions table (both sample Items checked, Check All / Uncheck All, Update Transactions button) and Plaid Items table (IDs, institutions, accounts, last polled, Update / Fix Item, Refresh, Link button) |
| `account1-plaid` | Linking an Account to Plaid | `/accounts/1` | Edit Account modal scrolled to the bottom: Plaid Account selector set to `Inst1 / Acct1 (foo)`, Save changes button |
| `plaid-update-result` | Plaid Update Result | `/plaid-update?item_ids=ALL` | Result table: Inst1 row with counts and statement IDs, Inst2 row with the sample error, Total row "1 Failed" |

Every existing entry keeps its filename, title, description and content.

## Result page change

The "Statement IDs" column of the Plaid Update result page shows each Item's statement
IDs (previously always blank).
